# Прогнозирование индекса селективности (SI) малых молекул против вируса оспы (VACV)

Репозиторий содержит решение задачи хакатона по разработке модели машинного обучения и автоматизированному сбору экспериментальной базы данных активности малых молекул против вируса осповакцины (*Vaccinia virus*, штамм VACV) и родственных ортопоксвирусов (*Poxviridae*).

## Архитектура проекта

- **data/train.csv** — стартовый обучающий набор (320 молекул).
- **data/test.csv** — тестовый набор для прогнозирования (597 молекул).
- **data/full_molecules_database_4000.csv** — собранная база реальных экспериментальных соединений с указанием DOI публикаций и ссылок на источники (2086 уникальных молекул: стартовый набор + 1766 соединений из открытых баз).
- **data/train_expanded_4000.csv** — расширенная база в структуре обучающего набора.
- **data/databases_by_500/** — разбиение собранной базы на пакеты по 500 записей.
- **fetch_data.py** — модуль автоматической выгрузки экспериментальных активностей из ChEMBL REST API и PubChem PUG REST API, резолвинга DOI статей и валидации химических структур через RDKit.
- **train_model.py** — модуль генерации молекулярных дескрипторов, обучения двухэтапного ансамбля и кросс-валидации.
- **run_pipeline.py** — единый воспроизводимый пайплайн для сквозного запуска всего решения.
- **submission_kaggle_exact.csv** и **submission_smiles_ml.csv** — итоговые файлы предсказаний в формате соревнования.

## Источники данных и валидация структур

Выгрузка экспериментальных значений (IC50, EC50, CC50, GI50) и метаданных публикаций выполняется из открытых баз:
- **ChEMBL REST API** — таргеты ортопоксвирусов (Vaccinia, Monkeypox, Cowpox, Variola, Ectromelia, Camelpox, Orf) и эндпоинт научных публикаций для получения DOI.
- **PubChem PUG REST API** — результаты биоскринингов антивирусной активности против Vaccinia virus.

Каждая молекула проходит проверку валентности, санитизацию, нормализацию единиц измерения к микромолям, удаление дубликатов и приведение к каноническому SMILES с помощью библиотеки RDKit.

## Архитектура модели машинного обучения (Hurdle + Multi-Target Ensemble)

Признаковое пространство объединяет 1270 характеристик:
- Отпечатки Моргана ECFP4 с радиусом 2 (1024 бита).
- Структурные ключи MACCS (167 бит).
- Топологические и физико-химические дескрипторы RDKit (15 признаков: молекулярная масса, липофильность LogP, полярная поверхность TPSA, доноры и акцепторы водородных связей, вращающиеся связи, ароматические кольца, доля sp3-углеродов, индексы Балабана и Берца, рефракция и площадь поверхности).
- Текстовые TF-IDF признаки вирусного штамма и клеточной культуры (64 признака).

Двухэтапная схема предсказания:
- **Классификатор активности (ExtraTreesClassifier)** — оценивает вероятность отсутствия ингибирующей активности, где целевой индекс равен константе 10000.0.
- **Раздельные регрессоры цитотоксичности и ингибирования (ExtraTreesRegressor)** — прогнозируют логарифмы CC50 и IC50 на всех доступных записях, включая внешние данные из ChEMBL и PubChem.
- **Ансамбль регрессоров индекса селективности (ExtraTreesRegressor + GradientBoostingRegressor)** — обучается на активных молекулах и формирует итоговый прогноз в логарифмической шкале.

## Метрики на кросс-валидации (5 фолдов, шкала log1p)

- **R2**: 0.5367 ± 0.0589
- **RMSE**: 2.2968
- **MAE**: 1.5293
